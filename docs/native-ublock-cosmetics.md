# Browser-owned uBlock Origin cosmetic subset

## Architecture and provenance

Argon uses the actual uBlock Origin `AstFilterParser`/`ExtSelectorCompiler` and
`contentscript-extra.js` procedural interpreter from
<https://github.com/gorhill/ublock/tree/3762a26fd65df422080c116e6a70d13bc8d57d62>.
The pinned Firefox manifest reports **1.9.15.101**. This is a commit pin, not a
claim that Argon implements that release's complete behavior.

`argon/adblock/ublock/` contains byte-identical upstream sources, their complete
GPLv3 license, the CSS-tree MIT license, and per-file SHA-256 provenance. The
parser's dependency closure includes `arglist-parser.js`, `jsonpath.js`, and
CSS-tree. `python3 scripts/build-ublock-cosmetics.py` verifies every upstream hash
before reproducing `procedural.js` from `procedural-bootstrap.js` and the complete,
unmodified `contentscript-extra.js`. Tests verify hashes, notices, generated bytes,
and both overlay copy and jar registration.

This is browser-owned integration, **not an extension presented as native**.
The windowless-chrome uBlock core (`argon/adblock/ublock-engine.sys.mjs`)
handles network matching, while `UBlockCosmetics` (`ublock-cosmetic.mjs`) is
compiled off the main thread in `compile-worker.mjs` from the same enabled
list/custom-filter generation; both publish atomically only after the durable
configuration/cache transaction succeeds. The core supplies `$generichide`,
`$specifichide`, and `$elemhide`; the uBO cosmetic index is authoritative for
CSS/procedural selection (`policy.mjs`). No extension messaging/background page
is used.

## Delivered and exercised

- Generic CSS selectors, exact and inherited hostname scopes, negated host scopes,
  entity (`example.*`) scopes (resolved via `Services.eTLD`), regular-expression
  (`/re/` and `/host\/path/`) host scopes, `#@#` exceptions, `$elemhide`,
  `$specifichide`, and `$generichide`, selected from enabled lists, custom
  subscriptions, and the custom filter editor.
- Real upstream procedural execution (`procedural.js`); packaged-browser fixtures
  prove `:has-text()`, `:upward()`, `:style()`, `:remove()`, `:remove-attr()`,
  `:remove-class()`, `:watch-attr()`, and `:shadow()`, including dynamically
  inserted nodes and restoration of visibility when a text predicate stops matching.
- Early collapsed static user-sheet CSS at `DOMWindowCreated` (`injectEarlyCosmetics`),
  plus Gecko Xray `openOrClosedShadowRoot` propagation of static hiding rules
  into open and closed Shadow DOM at `DOMContentLoaded`.
- Document-scoped Gecko user sheets, including pages with `style-src 'none'`.
  Script CSP is not loosened. Procedural code runs in the actual content window,
  not the parent/system realm or an alternate sandbox global. Only cloned rule
  data and a primitive marker prefix enter the installer; no privileged callback
  is passed. The page callback's Function constructor still throws `EvalError`
  with hash-only script CSP.
- User-sheet CSS is constructed exclusively from parent-selected parser output,
  **never from page-realm return values**. A hostile-page fixture replaces
  `JSON.stringify` to forge CSS; its forged sheet must not take effect.
- Coalesced mutation scheduling, upstream per-selector CPU budgets, 8 ms per-frame
  scheduling budget, own marker-mutation suppression, `pagehide` suspension, and
  `pageshow` resumption (verified with genuine `pageshow.persisted` BFCache
  restoration).
- Existing trusted top-level site switches (`no-cosmetic-filtering`), private
  per-tab cosmetic additions, list transactions, and network filtering remain
  authoritative via `UnifiedPolicy`.

`ArgonAdblock.engine.ublockCosmetics.diagnostics` is a browser-internal report with
`accepted`, `rejected`, reason counts and at most 50 sample raw rules. **Accepted
means indexed, not executed, matched, or proven equivalent to uBO.** Scriptlet/HTML/response-header rules are reported as `non-cosmetic-extended`
rather than misrepresented as executable cosmetics.

## Proven hard limits

- Static CSS rules (`##.sel`) penetrate **both open and early closed shadow roots**
  via Gecko Xray `openOrClosedShadowRoot` in `child.sys.mjs`. However, procedural
  `:shadow()` hooks `Element.prototype.attachShadow` inside `procedural.js` at
  `DOMContentLoaded`; **closed shadow roots attached before `DOMContentLoaded`
  are missed by procedural `:shadow()`** (`test_adblock_limits.py`).
- Scheduling is coalesced and enforces an 8 ms frame budget alongside upstream
  budgets, **not a hard preemption guarantee**: a single synchronous selector or
  complex regex evaluation can still block the frame until it finishes.
- HTML filtering (`##^` element removal on raw HTML) is **not supported** and is
  reported under `non-cosmetic-extended` diagnostics (`cap_html_filtering=false`).
- Procedural rules run in the actual content realm (to preserve document CSP), so
  a page can tamper with its own DOM/prototypes; isolated-world anti-tampering
  parity is not claimed. No page-controlled data is treated as privileged policy.

The uBlock Origin enterprise extension policy has been retired; all 9 parity
gates are verified via `node scripts/adblock-policy.mjs verify --evidence docs/parity-evidence.json`.

## Reproduction

```sh
python3 scripts/build-ublock-cosmetics.py
node --test tests/adblock/ublock-cosmetic.test.mjs
python3 scripts/dev-browser.py --sync-only
.cache/browser-venv/bin/python tests/browser/test_ublock_cosmetic.py
npm run test:browser:limits
npm run test:browser
```
